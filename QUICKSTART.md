# Быстрый старт

## Первые 30 минут

Запустите `nvim` и наберите `:Tutor` + Enter — интерактивный учебник на русском.
Вторая часть: `:Tutor vim-02-beginner`.

## Главное про режимы

| Режим | Зачем | Как попасть |
|---|---|---|
| **Normal** | команды, движение | `Esc` или `jk` |
| **Insert** | печать текста | `i` перед курсором, `a` после, `o` новая строка |
| **Visual** | выделение | `v` символы, `V` строки, `Ctrl-v` блок |
| **Командная строка** | `:w` сохранить, `:q` выйти | `:` |

Правка — это «глагол + объект»: `d` удалить, `c` изменить, `y` копировать.
`dw` — удалить слово, `dd` — строку, `ciw` — заменить слово, `ci(` — всё внутри скобок.
`u` — отменить, `.` — повторить последнее действие.

**Забыли клавишу?** Нажмите `Space` и подождите — появится меню. Или `Space ?` — шпаргалка.

## Цикл работы: C++

```bash
nvim hello.cpp
```

1. `i` — печатаете код. Подсказки появляются сами: `Tab` — выбрать, `Enter` — принять.
2. Ошибки подчёркиваются сразу. `Space e` — текст ошибки, `gra` — предложить исправление.
3. `Esc`, затем `Space w` — сохранить. Код отформатируется автоматически.
4. `Space r` — собрать и запустить (вывод появится снизу).
5. Отладка: курсор на нужную строку, `Space db` — точка останова, `F5` — старт,
   `F10` — следующая строка, `Space de` — посмотреть значение переменной.

`gd` — к определению функции, `Ctrl-o` — назад. `K` — документация.

## Rust

```bash
cargo new myapp && cd myapp && nvim src/main.rs
```

`Space r` вызовет `cargo run`. Подсказки типов показываются прямо в коде (`Space ch` — скрыть).

## Ассемблер (NASM)

```nasm
        global  _start
        section .text
_start:
        mov     rax, 60         ; exit
        xor     rdi, rdi
        syscall
```

Сохраните как `hello.asm`, `Space r` — соберёт через `nasm` + `ld` и запустит.
Если в файле есть `main`, линковка пойдёт через `gcc` — можно вызывать `printf`.
`K` на инструкции — её описание. Отладка через gdb: `Space db`, `F5`.

## Навигация по проекту

| Клавиша | Действие |
|---|---|
| `Space Space` | найти файл по части имени |
| `Space fg` | найти текст во всём проекте |
| `Space n` | дерево файлов (`a` создать, `d` удалить, `r` переименовать) |
| `Shift-h` / `Shift-l` | переключение между открытыми файлами |
| `Ctrl-h/j/k/l` | переход между окнами |
| `Ctrl-\` | плавающий терминал |
