
## ⌨️ 10 главных команд

| Команда | Что делает |
|---------|------------|
| `,e` | Открыть файловое дерево слева |
| `,ff` | Найти файл (начните печатать название) |
| `,fg` | Найти текст во всех файлах |
| `,w` | Сохранить файл |
| `Tab` / `Shift-Tab` | Переключаться между открытыми файлами |
| `F5` | Скомпилировать и запустить C++ |
| `gd` | Перейти к определению функции/класса |
| `K` | Показать документацию под курсором |
| `gcc` | Закомментировать/раскомментировать строку |
| `:q` | Выйти |

## 🎯 Первые шаги

### 1. Открыть файловое дерево
Нажмите `,e` - слева появится дерево файлов.
- `j`/`k` - вверх/вниз
- `Enter` - открыть файл
- `,e` - закрыть дерево

### 2. Найти файл
Нажмите `,ff` - появится поиск.
Начните печатать название файла - он найдется автоматически!
- `↑`/`↓` - выбор
- `Enter` - открыть

### 3. Написать C++ код
```bash
nvim test.cpp
```

Нажмите `i` чтобы начать печатать:
```cpp
#include <iostream>

int main() {
    std::cout << "Hello!" << std::endl;
    return 0;
}
```

Нажмите `Esc`, затем:
- `,w` - сохранить
- `F5` - скомпилировать и запустить!

### 4. Использовать автодополнение
Печатая код, нажмите `Ctrl-Space` для вызова автодополнения.
- `Tab` - выбрать следующее
- `Enter` - подтвердить
- `Esc` - отменить

### 5. Навигация по коду
Поставьте курсор на функцию и нажмите:
- `gd` - перейти к определению
- `K` - показать документацию
- `Ctrl-o` - вернуться назад

## 💡 Полезные трюки

### Множественное редактирование
1. Выделите текст в Visual mode (`v`)
2. Нажмите `J` или `K` - строки переместятся!

### Быстрое комментирование
1. `gcc` - закомментировать текущую строку
2. Выделите несколько строк (`V`), нажмите `gc`

### Поиск по содержимому
1. `,fg` - открыть live grep
2. Печатайте что ищете
3. Результаты обновляются в реальном времени!

### Работа с окнами
- `:split` - разделить по горизонтали
- `:vsplit` - разделить по вертикали
- `Ctrl-h/j/k/l` - переключаться между окнами
