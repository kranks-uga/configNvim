# Шпаргалка по nvim  (открыть: Space ?   закрыть: q)

## Режимы
Esc / jk      -> Normal (команды)       i a o      -> Insert (печать)
v V Ctrl-v    -> Visual (выделение)     :          -> командная строка

## Движение (Normal)
h j k l       влево вниз вверх вправо   w b e      по словам
0 ^ $         начало / первый символ / конец строки
gg G          начало / конец файла      42G  :42   строка 42
{ }           по абзацам (функциям)     %          к парной скобке
Ctrl-d Ctrl-u полэкрана вниз/вверх      Ctrl-o Ctrl-i  назад/вперёд по прыжкам
f<c> t<c>     прыжок к символу в строке ;  ,        повторить f/t
/text  n N    поиск вперёд, след/пред   *          искать слово под курсором

## Правка = глагол + (число) + объект
d удалить  c изменить  y копировать  p вставить  u отмена  Ctrl-r повтор  . повторить
dd yy cc      строка целиком            dw  d$  D   слово / до конца строки
ciw  ci"  ci( di{   изменить/удалить слово, в кавычках, в скобках, в блоке
>> <<         отступ                    gcc / gc    закомментировать строку / выделение
ysiw"  ds"  cs"'    обернуть в кавычки / убрать / заменить
:%s/old/new/g       замена во всём файле

## Файлы и окна
Space Space / Space ff   найти файл      Space fg   поиск текста по проекту
Space fr   недавние       Space n   дерево файлов (a создать, d удалить, r переименовать)
Shift-h / Shift-l   пред/след буфер     Space x   закрыть буфер
Space w  сохранить   Space q  закрыть окно   :vsp  :sp  разделить
Ctrl-h/j/k/l        перейти между окнами
Ctrl-\              плавающий терминал  (Esc Esc — выйти в Normal в терминале)

## Код (LSP)
gd         к определению           grr      все использования
K          документация            gri      реализации
grn        переименовать           gra      quick fix / действия
Space co   .h <-> .cpp             Space ch  подсказки типов вкл/выкл
Space cf   отформатировать сейчас   Space cF  автоформат при сохранении вкл/выкл
Space e    текст ошибки под курсором    ]d [d   след/пред ошибка
Space tt   все ошибки проекта      Space fs   символы файла
Автодополнение: Tab/Shift-Tab выбор, Enter принять, Ctrl-Space открыть
Ctrl-k (Insert)  сигнатура функции

## Сборка и запуск
Space r    собрать и запустить текущий файл      Space b   только собрать
  C: gcc -std=c17 -g -Wall -Wextra   C++: g++ -std=c++23 ...
  Rust: cargo run (если есть Cargo.toml) иначе rustc
  NASM: nasm -f elf64 -g + ld (или gcc, если есть main)
  Есть Makefile -> make / make run

## Отладка
Space db   точка останова          F5   старт / продолжить
F10 шаг через   F11 внутрь   F12 наружу      Space dr  до курсора
Space de   значение выражения      Space dt  стоп     Space du  панели
Сначала Space b (собрать с -g), потом F5 — путь к бинарнику подставится сам.

## Git
]h [h  изменения   Space gp  показать   Space gr  откатить   Space gb  blame
